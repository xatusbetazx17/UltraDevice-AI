# Engineering scope

This branch controls a USB bench prototype's onboard LED and supplies analytical
power/thermal models. It does not implement biological procedures, transformation,
medical diagnosis or body-mounted actuators.

Thermal limits are example values. Chip temperature is not skin temperature; a
software cutoff does not replace pack protection or an independent electrical cutoff.
Use the physical acceptance record before extending the assembly. Run fault-injection
tests using simulated readings rather than heating a device on a person.

Keep unknown measurements explicit, minimize personal data in logs, and identify
simulated versus measured evidence. Do not advertise speculative features or desktop
test results as validated capabilities of a physical product.
